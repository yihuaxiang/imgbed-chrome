# 图床小镇助手（免费图床）Chrome 插件

这是一个简单的 Chrome 浏览器插件，让你可以快速访问 imgbed.cn 图床服务。

## 功能特性

- 点击插件图标即可打开 imgbed.cn 图床
- 弹窗尺寸优化，方便上传和管理图片
- 无需额外权限，安全可靠

## 安装方法

### 方法一：开发者模式安装（推荐）

1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 在右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目文件夹
6. 完成！现在你可以在浏览器工具栏看到插件图标

### 方法二：打包安装

1. 在 Chrome 扩展管理页面 (`chrome://extensions/`)
2. 开启开发者模式
3. 点击「打包扩展程序」
4. 选择本项目文件夹
5. 生成的 `.crx` 文件可以分享给其他人安装

## 使用方法

1. 点击浏览器工具栏中的插件图标
2. 弹窗会显示加载动画，等待 imgbed.cn 加载完成
3. 加载完成后即可在弹窗中直接上传和管理图片

> 提示：首次打开可能需要几秒加载时间，这是正常现象。

## 自定义图标

项目中的图标文件位于 `icons/` 目录下，需要以下三个尺寸：

- `icon16.png` - 16x16 像素
- `icon48.png` - 48x48 像素
- `icon128.png` - 128x128 像素

你可以使用 `icons/icon.svg` 作为源文件，通过在线工具（如 https://cloudconvert.com/svg-to-png）转换为不同尺寸的 PNG，或直接替换为自己的图标。

## 技术说明

- **Manifest Version**: V3 (Chrome 扩展最新版本)
- **权限要求**: 无需特殊权限
- **兼容性**: Chrome 88+ / Edge 88+

## 常见问题

**Q: 加载速度慢怎么办？**
A: 首次加载需要从网络获取 imgbed.cn 的内容，速度取决于网络状况。加载完成后会显示完整网站。

**Q: 为什么显示加载动画？**
A: 这是正常的，表示正在从服务器加载网站内容。通常几秒钟就能加载完成。

**Q: 如何调整弹窗尺寸？**
A: 可以在 `popup.html` 中修改 `body` 的 `width` 和 `height` 来调整弹窗尺寸（默认 800x600）。

**Q: 如何更新插件？**
A: 修改代码后，在扩展管理页面点击刷新按钮即可。
